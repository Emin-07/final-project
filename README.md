# Todo Scheduler

Умный список задач с поддержкой повторяющихся дел. Позволяет создавать задачи, настраивать расписание повторений, отмечать выполненные и управлять ими через веб-интерфейс. Данные хранятся в SQLite, доступ защищён паролем через JWT.

## Задания со звёздочкой

Все задания выполнены.

## Запуск локально

Создайте `.env` файл в корне проекта:

```
TODO_PORT=":7540"
TODO_DBFILE="scheduler.db"
TODO_PASSWORD="1234"
JWT_KEY="ваш-секретный-ключ"
```

Запуск:

```bash
make run
```

Или с горячей перезагрузкой (требует `CompileDaemon`):

```bash
make dev
```

Приложение будет доступно по адресу: `http://localhost:7540`

## Запуск тестов

В файле `tests/settings.go` укажите параметры:

```go
var Port = 7540          // порт, на котором запущен сервер
var DBFile = "../scheduler.db"
var FullNextDate = false // true — если выполнено задание со звёздочкой по next_date
var Search = false       // true — если реализован поиск задач
var Token = ``           // JWT-токен (получить после авторизации)
```

Запуск:

```bash
make test
```

## Docker

Сборка образа:

```bash
make docker-build
```

Запуск контейнера:

```bash
make docker-run
```

Приложение будет доступно по адресу: `http://localhost:7540`
